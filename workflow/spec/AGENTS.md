# 一時的な検証計画

この文書はworkflow/spec/AGENTS.mdに置く正本であり、一時的な検証計画の扱いを定める。上位規則はworkflow/AGENTS.mdとAGENTS.mdによる。この置場には、まだ実行形の検証や証拠の判定処理にできない検証だけを置く。

- 実装済みテストの入力、期待値、境界値、合否判定を複製しない
- 外部環境を要する項目には必要な環境と残す証拠を記載する
- 対応するテストが完成した項目は削除し、項目がなくなった文書は廃止する
- 一時的な証拠の保存先は各XRiftワールドディレクトリ配下の`tmp/`に従う。実行する検証はリポジトリ規則の検証節による
