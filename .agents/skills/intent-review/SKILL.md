# 要求文書のレビュー

要求文書は設計判断の指針となるため、人間が変更したあとは以下の指針に基づいて内容をレビューする。レビューは指摘までとし、承認の代わりにしない。

## 主な確認項目

- Visionに対して矛盾した内容になっていないか
- 他の要求文書と矛盾していないか
- やりたいことが明確であること
- 具体的な手段の指定ではなく達成したい状態を示しているか
- 非目標が明確か
- 明文化されていない多くの制約を仮定していないか
- 影響を受けるDesignとの整合が取れているか
- 要求内容の変更は人間が判断しているか

## 改善提案

人間が具体的、定量的な内容をあまり記述しておらず、かつエージェントが一般論や既存のコードベース、調査結果などに基づいて助言できる場合、以下の内容について改善提案を行う。

- 数が明確でない内容に対して具体的な数値の範囲を提案する
- 感覚的な内容に対して具体的な動作に基づく内容を提案する
