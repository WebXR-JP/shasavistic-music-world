# `/commit`

現在の依頼で完了した変更を、リポジトリ規則（AGENTS.md）のコミット規則に従って一つのローカルコミットにする。$ARGUMENTSがある場合は、目的または対象範囲の指定として扱う。

- このコマンドの実行を、一つのローカルコミットを作成する明示的な依頼として扱う。push、amend、rebase、fixupの許可には含めない。
- 作業ツリーと現在の依頼を照合し、今回所有するファイルを確定する。対象が複数の取り消し理由に分かれる場合、別作業の変更と区別できない場合、または同一ファイル内に変更が混在する場合はコミットせず、人間へ判断を返す。
- 変更内容に応じた独立検証と審査の結果を確認する。設計文書の審査はdesign-reviewerを導入済みの場合にdesign-reviewer、要求正本の変更には人間の判断とintent-reviewを必要とする。ただしintent-reviewは要求正本を導入した構成でのみ使う。導入していない審査手段がある場合は既存の審査手段または人間の確認へ戻す。確認後に差分が変化している場合は必要な確認をやり直す。
- 対象パス、ポリシー上限以内の日本語件名、変更理由、実行済みの検証と結果、必要な参照と許可をcommitterへ渡す。ステージとコミットはcommitterだけが行う。コミット操作には`node .opencode/scripts/commit-change.mjs`を使い、件名上限と見出し語は`.opencode/commit-policy.json`に従う。
- committerの結果を確認し、コミットID、件名、対象パス、未コミットの残りを報告する。
